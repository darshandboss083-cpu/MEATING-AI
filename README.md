Meeting AI

AI Meeting Intelligence is a web-based project that converts meeting transcripts into useful and organized information.

Overview

Meetings often contain a lot of information, making it difficult to remember important discussions, tasks, and deadlines. Meeting AI helps organize a meeting transcript into clear sections such as summary, important discussions, action items, and deadlines.

Features

* Add or paste a meeting transcript
* Analyze meeting content
* Generate a meeting summary
* Identify important discussions
* Extract action items
* Identify deadlines
* Simple and user-friendly interface
* Responsive design

Technologies Used

* HTML
* CSS
* JavaScript

How It Works

1. Enter or paste the meeting transcript.
2. Click Analyze Meeting.
3. JavaScript processes the transcript.
4. The application displays the results in organized sections.
5. Users can quickly understand the important information from the meeting.
